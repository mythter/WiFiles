# Wi-Files

Windows and Android application for sending and receiving files over local and global networks.

# Key Features
- Local transfer (LAN) without the need to connect to the Internet
- Global transfer (WAN) using intermediate server
- Encrypted (using ECDH algorithm for creating shared secret and AES algorithm for encryption)
- Fast (using TCP for local transfer is 2-3 times faster than HTTP)

# Supported Platforms
- Windows 10 and higher
- Android 7 and higher (tested on 8 and 11)

# Powered by
- [MAUI Blazor Hybrid](https://dotnet.microsoft.com/en-us/apps/aspnet/web-apps/blazor)
- [.NET 8](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [SignalR](https://github.com/SignalR/SignalR)
